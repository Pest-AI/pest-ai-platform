# PEST AI OS — Portail de documentation développeurs

Site de documentation destiné aux développeurs actuels et futurs, sur le modèle des portails d'API publics :

- **Guides** (démarrage, authentification, espaces de travail, synchronisation hors ligne) avec Docusaurus ;
- **Référence API interactive** générée automatiquement depuis le schéma OpenAPI du backend, avec Scalar.

Hébergement : Vercel. Voir [ADR-0006](../docs/01-architecture/adr/0006-documentation-api.md). Le code arrive au **J4** du planning.
